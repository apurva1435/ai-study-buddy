# AI Study Buddy

An AI-powered learning assistant designed to help students understand concepts through intelligent question answering and an interactive conversational interface.

## Features

- AI-powered Question Answering
- Interactive Chat Interface
- Persistent Conversation History
- FastAPI Backend
- React Frontend
- SQLite Database

## Tech Stack

### Backend
- Python
- FastAPI
- SQLite

### Frontend
- React

## Project Structure

```
StudyBuddy
│
├── backend
├── frontend
├── database
└── README.md
```

## How it Works

1. User asks a question.
2. Backend processes the request.
3. AI generates a response.
4. Conversation history is stored.
5. User continues learning through interactive discussions.
